# Reproducibility and limitations

## Execution order

1. Obtain source datasets under their original terms and create the processed response matrices with the exact preprocessing protocols.
2. Generate or obtain aligned GenePT and UCE feature matrices; run `python scripts/preflight.py`.
3. Prepare RPE1 response matrices using the Step08 workflow if performing K562-to-RPE1 evaluation.
4. Run Step10A to train K562 models and save target splits, checkpoints and predictions.
5. Prepare HepG2/Jurkat matrices using the Step11B-2A expanded-threshold workflow and inspect the coverage audit. **The published Step11B-4 script expects** `data/external_validation/step11B_2A_expanded_minbatch1/{HepG2,Jurkat}/response_matrix_k562_gene_intersection.npz`.
6. Run Step11B-4 frozen transfer, then Step11B-5/6 and downstream diagnostics.
7. Render manuscript figures from verified CSV/NPZ inputs.

## Interpretation limits

- Input `delta` is an aggregated perturbation response, not a single-cell training matrix.
- Target-level held-out evaluation and external cell-line transfer are different axes of generalization.
- For external evaluation, always report whether a perturbation was K562 train-seen or K562 test-held-out.
- Zero-response baseline skill is necessary alongside PCC. Micro and macro skill may disagree.
- Response-strength filtering uses observed truth and is **diagnostic**, not a deployable selection rule.
- Repeated random seeds are computational replicates, not independent experiments.
- Representative perturbations are descriptive examples, not unbiased performance estimates.
- Enrichment results are exploratory and depend on gene selection, gene universe and correction scope.

## Known release limitations

- Raw data downloads, data accessions, checksums and licenses are not provided in the supplied source snapshot; these must be completed before claiming end-to-end reproducibility.
- The original Step scripts retain historical names and some historical experimental branches. The dispatcher intentionally does not alter their algorithms.
- Full GPU/CPU multi-seed model training and Figure 1–8 regeneration **have not been executed in the packaging environment**.
- Step11B-4 expects outputs from Step11B-2A; there is no one-command pipeline for all preprocessing stages.
- Figure 8 selected terms are a curated view of the enrichment results, not a new statistical analysis.
